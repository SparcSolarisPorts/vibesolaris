Pasting: terminal bracketed paste (ESC[200~...ESC[201~), up to 256 KiB per prompt. Pasted newlines do not submit.
Images: /paste-image on macOS copies a PNG from clipboard into an image attachment; /attach path works on all platforms.
Note: ordinary Cmd+V of an image in macOS Terminal usually does not transmit pixels to a CLI. Use /paste-image.
Existing TUI redraw for very long text is not yet a bounded viewport.
